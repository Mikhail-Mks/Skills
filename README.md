# AI Agent Skills

A collection of AI agent skills

## Skills Overview

| Skill | Description |
|-------|-------------|
| dataset-generator | Generates realistic CSV datasets, data dictionaries, and project briefs from job postings. Creates industry-appropriate data with configurable size (small/medium/large) and quality (clean/messy) settings. |
| epub | Converts Markdown or text content into professional EPUB ebooks. Supports multiple chapters, automatic table of contents, cover images, and metadata configuration. |
