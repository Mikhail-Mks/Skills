# AI Agent Skills

A collection of AI agent Skills.

## Skills Overview

| Skill | Description |
|-------|-------------|
| [ai-seo](https://github.com/Mikhail-Mks/Skills/tree/main/ai-seo) | Optimizes content for AI search and LLM citations. |
| [brainstorm](https://github.com/Mikhail-Mks/Skills/tree/main/brainstorm) | Open-ended brainstorming and idea generation partner. 4 modes: Open Exploration, Problem-Space Exploration, Feature/Direction, Name Storming. Uses creativity frameworks (SCAMPER, Crazy 8s, etc.). Triggers on "brainstorm", "I need ideas", "help me explore", "what if", "blue sky thinking", and similar ideation requests. |
| [capture](https://github.com/Mikhail-Mks/Skills/tree/main/capture) | Captures and organizes chaotic brain dumps into a structured 4-section actionable system (Projects/Ideas, Tasks, Connections, How I Can Help) with zero information loss. Fast-to-action: no upfront intake, outputs an organized structure ending with a directive question. Triggers on "brain dump", "capture this", "organize my thoughts", and similar phrases. |
| [content-trend-analyzer](https://github.com/Mikhail-Mks/Skills/tree/main/content-trend-analyzer) | Analyzes current trends |
| [dataset-generator](https://github.com/Mikhail-Mks/Skills/tree/main/dataset-generator) | Generates realistic datasets, data dictionaries, and project briefs from job postings or from scratch. |
| [epub](https://github.com/Mikhail-Mks/Skills/tree/main/epub) | Converts Markdown or text content into  EPUB ebooks. Supports multiple chapters, automatic table of contents, cover images, and metadata configuration. |
| [fact-checker](https://github.com/Mikhail-Mks/Skills/tree/main/fact-checker) | Systematic fact verification and misinformation detection. Extracts assertions, classifies claim types (statistical, historical, scientific, etc.), cross-references authoritative sources, rates claims on a 6-level scale with confidence scores (0.0–1.0), and flags manipulation patterns. Includes source quality hierarchy, best practices, and edge cases.|
